Dates importantes du calendrier

Éditeur du fichier de dates importantes pour Publical, l'extension Inkscape de calendrier semestriel. Regroupez vos dates par catégorie, donnez une couleur à chaque catégorie, puis enregistrez le fichier JSON à charger dans l'extension (onglet Contenu, champ « Fichier d'événements »).

Le brouillon est conservé dans ce navigateur. Vous pouvez aussi glisser un fichier JSON sur cette page pour le modifier.
